# Sponsoring Fairyfly

Fairyfly is a backend JavaScript runtime in Zig on QuickJS — built for fast
startup, low memory use, and a codebase you can actually audit. Batteries
included: HTTP server, fetch client, WebSocket, SQLite, Postgres, Workers,
WebCrypto, and FFI, driven by plain `ff` commands.

Sponsor: <https://github.com/sponsors/AbdElMajidOuhamane>

## Where the money goes

- CI runners and ARM/macOS hardware for the benchmark and test matrix
- Contributor bounties (Postgres/TLS/HTTP-2 hardening, known-issue fixes)
- Security fix response and vendor upgrades
- Docs, examples, and signed prebuilt releases for macOS/Linux + Docker

## Pledges

- Fairyfly stays **MPL-2.0 forever**. Sponsorship funds maintenance and
  velocity — never paywalled features, never license influence.
- Logo placement is a thank-you, not an endorsement and not a support SLA.
- If priorities ever conflict with sponsor requests, open GitHub issues
  and maintainer judgment win — a public roadmap file will land later
  and take over from there.

## For companies needing invoices

GitHub Sponsors receipts work for most teams. If you need a formal invoice
from a nonprofit fiscal host, open an issue — fiscal-hosted invoicing is on
the table once corporate demand justifies it.
